# Project Scope

## Migration Goals
- Migrate Telcom Company e-commerce from monolithic to micro-frontend architecture
- Target: Angular 18 with Signals
- Reduce bundle size by 40%
- Improve TTI and Core Web Vitals
- Enable independent deployment of features

## Team Structure
- Frontend: 5+ teams
- Backend: Separate Spring Boot microservices
- Infrastructure: Azure cloud native

## Phases
1. NX workspace & shared libs
2. Module Federation setup
3. Feature MFE implementations
4. Migration to Angular 18
5. Performance optimization
